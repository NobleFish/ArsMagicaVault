R: Touch, D: Sun, T: Ind\
This spell enlarges an inanimate object originally no bigger than a
large chest. The object doubles in each dimension and increases its
weight eight times. The size increase is based on the object's original,
natural size, so casting the spell more than once on an object has no
effect. Noble elements like gold, silver, and gems, are not affected by
this spell. If any part of the item resists growth, the item as a whole
does not grow. Casting requisites are required for the appropriate Form
for the target.\
(Base 4, +1 Touch, +2 Sun, +1 stone)
