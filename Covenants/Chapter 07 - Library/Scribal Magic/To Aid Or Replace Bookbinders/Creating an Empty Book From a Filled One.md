PeAn 3 R: Touch, D: Mom, T: Ind

This spell creates a palimpsest (a book that has had its writing scraped
away so that it can be reused) from an existing book. It does this by
flaking away a thin layer from both sides of each page.

An Perception + Finesse roll determines the skill with which the
previous writing has been removed.

*(Base 2, +1 Touch)*
